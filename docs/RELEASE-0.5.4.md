# 0.5.4 — Simpler launcher settings

A cleaner settings window with consistent headings, better spacing and simpler
descriptions.

- Graphics presets have been removed. Adjust each picture setting individually.
- Display now has a clearly named **V-Sync** setting with **On** and **Off** choices.
- The Advanced tab has been removed.

Your saves and existing preferences are kept. Updating from 0.5.3 does **not**
require rebuilding the game. This release includes the opening Queen battle
fix from 0.5.3.

Download **EnchantedArmsPC-0.5.4-windows-x64.zip** from Assets, extract it, then
open **EnchantedArmsLauncher.exe**. New players supply their own supported
Enchanted Arms ISO.
