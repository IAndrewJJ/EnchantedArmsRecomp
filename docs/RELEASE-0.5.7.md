# 0.5.7 — V-Sync always enabled

V-Sync is now always enabled, and its setting has been removed from the launcher.
This applies automatically even if you previously turned it off.

Your 30 or 60 FPS choice, other graphics settings and saves are kept.
Updating from 0.5.6 does not require rebuilding the game. Use **Settings → Updates**,
then close and reopen the game to apply the change.

For a new installation, download **EnchantedArmsPC-0.5.7-windows-x64.zip** from
Assets and extract it before opening **EnchantedArmsLauncher.exe**. Supply your
own supported game ISO.
