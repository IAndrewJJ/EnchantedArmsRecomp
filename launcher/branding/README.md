# EnchantedArmsPC application icon

Original arcane gauntlet/crystal artwork created with the built-in image-generation
tool and approved by the project owner. No game texture or official logo was used
as an input. `EnchantedArmsPC.png` is the transparent source image;
`EnchantedArmsPC.ico` contains 16, 20, 24, 32, 40, 48, 64, 96, 128 and 256 pixel
frames for Windows Explorer, desktop shortcuts and application windows.

The launcher build embeds the ICO. Desktop shortcuts reference icon index 0 in
`EnchantedArmsLauncher.exe`; no separate icon installation is needed.

## Final generation prompt

Use case: logo-brand. Asset type: a finished Windows desktop application icon for EnchantedArmsPC, a fan-made native PC version of Enchanted Arms. Primary request: an original arcane fantasy emblem inspired by the game's enchanted-arm theme and the launcher's navy, turquoise and muted gold visual design. Subject: one bold stylized golden armored gauntlet cradling a luminous faceted cyan crystal, enclosed by a simple dark-navy medallion with a restrained gold rim. Style: premium early-2000s Japanese RPG fantasy emblem, clean sculpted shapes, subtle metal and crystal highlights, crisp edges and strong silhouette. Composition: square canvas, one centered icon filling about 85 percent of the square, balanced, readable at 16, 32 and 48 pixels. Background: genuine transparency outside the medallion. Constraints: no text, no lettering, no watermark, no official company logos, no tiny ornamental runes, no scenery, no multiple icon variations or mockup. Keep the silhouette simple, contrast strong, and glow restrained.
